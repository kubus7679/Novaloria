# Novaloria 0.0.1

Erste veröffentlichte Version von Novaloria, einem unabhängigen nativen
macOS-Client für das rundenbasierte Strategiespiel FreeCol.

## Funktionen

- Verbindung zu einem laufenden FreeCol-Server über das FreeCol-TCP/XML-Protokoll
- Lokale Java-Partien erstellen und Spielstände laden
- Native macOS-Oberfläche mit Karte, Kolonien, Europa, Diplomatie und Handelsrouten
- Spielstände über den Java-Server speichern; dafür ist eine optionale
  Server-Erweiterung erforderlich

## Voraussetzungen

- macOS 14 oder neuer
- Für lokale Partien und das Laden von Spielständen: eine passende
  FreeCol-Installation und Java-Version
- Für die Verbindung mit einem bereits laufenden Server ist keine lokale
  Java-Installation erforderlich

## Bekannte Einschränkungen

- Die Benutzeroberfläche ist derzeit ausschließlich auf Deutsch verfügbar.
- Das FreeCol-Protokoll verwendet unverschlüsseltes TCP. Verbindungen sollten
  daher nur über vertrauenswürdige Netzwerke verwendet werden.
- Das DMG ist nicht signiert oder notarisiert; macOS kann beim Öffnen eine
  Sicherheitswarnung anzeigen.

Novaloria ist ein unabhängiges Community-Projekt und steht in keiner offiziellen
Verbindung zum FreeCol-Projekt. Lizenz- und Herkunftshinweise zu FreeCol-
Ressourcen stehen in `THIRD_PARTY_NOTICES.md`.
