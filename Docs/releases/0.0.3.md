# Novaloria 0.0.3

This release improves colony management, map presentation, and the visual
identity of the game, while making the interface more consistent across all
supported languages.

## What's new since 0.0.2

- Colony management now gives a clearer overview of workplaces, production,
  food and growth, construction, transport, and warehouse stock. Production
  estimates and worker assignments have been improved.
- FreeCol mods can be selected in Novaloria, including the new Novaloria Atlas
  graphics mod with expanded artwork for terrain, units, settlements, buildings,
  goods, and more.
- Native settlements have a dedicated alarm display and improved interaction
  and information panels.
- The map and colony views have been visually refined with expanded atlas
  artwork, clearer territory and terrain presentation, and faster tile image
  loading.
- Colopedia content and game messages have been expanded. The interface and
  additional combat and mission messages are localized in German, English, and
  Spanish.
- Protocol, map interaction, and colony behavior have additional test coverage.

## Requirements and notes

- macOS 14 or later
- A compatible FreeCol installation and Java version are required to start
  local games and load savegames.
- No local Java installation is needed to connect to an existing server.
- The FreeCol protocol uses unencrypted TCP. Connect only over trusted
  networks.
- The DMG is not signed or notarized; macOS may show a security warning when
  you open it.
