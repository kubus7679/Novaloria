# Novaloria 0.0.2

This release adds a multilingual interface and expands colony management and
the presentation of the game world.

## What's new

- The interface is now available in German, English, and Spanish. Choose a
  language on the startup screen or in the in-game preferences.
- Visit and interact with native settlements through a dedicated panel, and
  purchase land through a new interface.
- Colony production and efficiency are easier to review. Workplaces, terrain,
  and production calculations have been expanded.
- The map presents territory borders and terrain information more clearly,
  alongside a visual refresh of the colony view.
- Additional tests cover map and settlement interactions as well as language
  selection.

## Requirements and notes

- macOS 14 or later
- A compatible FreeCol installation and Java version are required to start
  local games and load savegames.
- No local Java installation is needed to connect to an existing server.
- The FreeCol protocol uses unencrypted TCP. Connect only over trusted
  networks.
- The DMG is not signed or notarized; macOS may show a security warning when
  you open it.
